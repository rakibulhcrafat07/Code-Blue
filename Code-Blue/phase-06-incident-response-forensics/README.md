# Phase 6 — Incident Response & Forensics

This is where "we got an alert" turns into "here's exactly what happened, when, and how we're recovering." Three projects, each drilling a different forensic discipline, because this is the phase most people under-invest in.

**Suggested pace:** Month 3–4
**Difficulty:** Advanced

## Topics

- [ ] NIST SP 800-61 IR lifecycle: Preparation → Detection → Containment → Eradication → Recovery → Lessons Learned
- [ ] Chain of custody and evidence-handling rules
- [ ] Memory forensics with Volatility3
- [ ] Disk forensics and timeline analysis with Autopsy / KAPE
- [ ] Basic malware triage: static analysis, sandbox detonation (Any.Run)
- [ ] Writing an incident report that holds up: timeline, IOCs, impact, remediation
