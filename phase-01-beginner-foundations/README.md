# Phase 1 — Beginner Foundations

Before touching any blue team tooling, get comfortable with how a computer, a network, and an operating system actually behave. Everything after this phase assumes this is solid.

**Suggested pace:** Month 1
**Difficulty:** Beginner

## Topics

- [ ] Linux command line: filesystem hierarchy, permissions, processes, package managers (apt/yum)
- [ ] Windows basics: Task Manager, Services, Registry concepts, Control Panel / Settings
- [ ] Networking primer: IP addressing, MAC addresses, router vs. switch, how a LAN works
- [ ] Scripting basics: small Python or Bash scripts (file parsing, simple automation)
- [ ] Virtualization: what a VM is, snapshots, host-only / isolated networks
- [ ] Core security vocabulary: CIA triad, malware, phishing, exploit, vulnerability
