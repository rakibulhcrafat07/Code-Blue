# Project 2 — Linux CLI for Blue Teamers

**Phase:** [1 — Beginner Foundations](../)
**Status:** ⬜ To Do

## Objective

Get fast and comfortable on the Linux command line specifically for the tasks a blue teamer repeats daily: reading logs, filtering text, checking processes.

## Tasks

- [ ] Navigate the filesystem and manage permissions (`ls`, `cd`, `chmod`, `chown`)
- [ ] Filter and search text with `grep`, `awk`, `sed`, `cut`
- [ ] Inspect running processes and network sockets (`ps`, `top`, `ss`, `netstat`)
- [ ] Read and tail logs (`less`, `tail -f`, `journalctl`)
- [ ] Write a one-line pipeline that extracts failed SSH login attempts from `/var/log/auth.log`
- [ ] Package the above into a short cheat-sheet you'll actually reuse later

## Tools

A Linux VM (from Project 1), `/var/log/auth.log` or `journalctl` output to practice against

## Deliverable

A personal Linux CLI cheat-sheet (markdown) with the commands above and one working log-filtering one-liner you wrote yourself.
