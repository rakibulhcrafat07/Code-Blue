# Phase 2 — Networking Deep Dive

Every detection is ultimately a network or host signal being read correctly. You can't spot abnormal traffic until you know what normal looks like.

**Suggested pace:** Month 1–2
**Difficulty:** Beginner–Intermediate

## Topics

- [ ] OSI and TCP/IP models, encapsulation
- [ ] Subnetting and CIDR notation, calculated by hand
- [ ] DNS resolution flow, DHCP lease process
- [ ] TCP three-way handshake; common ports (21, 22, 25, 53, 80, 443, 445, 3389)
- [ ] HTTP/HTTPS request-response cycle, TLS handshake basics
- [ ] Wireshark and tcpdump: capturing and filtering live traffic
- [ ] Recognizing suspicious patterns in a pcap (beaconing, port scans)
