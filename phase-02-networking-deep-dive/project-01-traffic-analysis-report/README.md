# Project 1 — Traffic Analysis Report

**Phase:** [2 — Networking Deep Dive](../)
**Status:** ⬜ To Do

## Objective

Practice reading a packet capture like an analyst would: identify hosts, protocols, and anything that looks off.

## Tasks

- [ ] Download a sample pcap from [malware-traffic-analysis.net](https://www.malware-traffic-analysis.net/)
- [ ] Open it in Wireshark; identify the hosts involved (IP/MAC) and the protocols in play
- [ ] Use display filters to isolate DNS, HTTP, and any unusual ports
- [ ] Follow at least one TCP/HTTP stream end to end
- [ ] Flag anything anomalous — repeated beacon-like connections, unexpected ports, plaintext credentials, etc.
- [ ] Write a one-page findings report

## Tools

Wireshark, (optional) tcpdump for capture practice, NetworkMiner for artifact extraction

## Deliverable

A one-page report: which IPs/hosts were involved, protocols observed, timeline of events, and what — if anything — looked suspicious and why.
