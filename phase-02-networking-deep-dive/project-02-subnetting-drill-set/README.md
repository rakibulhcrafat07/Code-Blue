**Phase:** [2 — Networking Deep Dive](../)

## Objective

Get fast enough at subnetting to do it in your head — this comes up constantly when scoping what's "in-network" during an investigation.

## Tasks

- [ ] Work through CIDR notation basics (/24, /25, /28, etc.) by hand
- [ ] Solve at least 20 subnetting problems (network address, broadcast address, usable host range, next subnet)
- [ ] Time yourself on the last 10 — aim to get each under 60 seconds
- [ ] Apply it to your own lab: write out the actual subnet plan for the host-only network from Project 1

## Tools

Pen and paper (deliberately no calculator for the drills), a subnet calculator only to check answers afterward

## Deliverable

Your worked answer sheet for the 20 problems, plus the subnet plan for your own lab network.
