# Project 3 — Build a Packet Sniffer

**Phase:** [2 — Networking Deep Dive](../)
**Status:** ⬜ To Do

## Objective

Understand packet structure well enough to parse it yourself, not just read it in a GUI.

## Tasks

- [ ] Write a Python script using Scapy (or raw sockets) that captures live traffic on the lab network
- [ ] Parse and print source/destination IP, protocol, and port for each packet
- [ ] Add a filter flag so it can watch for one specific thing (e.g., all traffic to port 22, or all DNS queries)
- [ ] Test it by generating traffic from the other lab VM and confirming it's captured correctly
- [ ] Compare your output against the same traffic viewed in Wireshark

## Tools

Python, Scapy

## Deliverable

The script itself (`sniffer.py`) plus a short note on what it captures and how to run it.
