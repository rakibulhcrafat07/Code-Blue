# Project 3 — Sysmon Config Tuning

**Phase:** [3 — OS Internals & Logging](../)
**Status:** ⬜ To Do

## Objective

Learn to customize a Sysmon configuration instead of just using someone else's defaults.

## Tasks

- [ ] Read through the SwiftOnSecurity config XML and understand its structure (rules, groups, include/exclude)
- [ ] Identify what it logs heavily by default and why
- [ ] Add one custom rule of your own (e.g., flag a specific process name or command-line pattern)
- [ ] Add one exclusion rule to cut noise from a known-benign, high-volume source on your VM
- [ ] Reload Sysmon with your modified config and confirm both changes work as expected

## Tools

Sysmon, a text/XML editor

## Deliverable

Your modified `sysmon-config.xml` plus a short note on what you added, why, and how you verified it worked.
