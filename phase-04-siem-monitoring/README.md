# Phase 4 — SIEM & Monitoring

Time to pull the scattered logs from Phase 3 into one searchable, alertable place — the core job of a SIEM.

**Suggested pace:** Month 2–3
**Difficulty:** Intermediate

## Topics

- [ ] SIEM concepts: ingestion, normalization, correlation, alerting
- [ ] Install Wazuh or the ELK stack (Elasticsearch + Logstash + Kibana) in the lab
- [ ] Forward Windows/Linux logs to the SIEM (Winlogbeat/Filebeat or Wazuh agent)
- [ ] Learn Splunk Free / SPL basics as an alternative or supplement
- [ ] Build dashboards: login attempts, top talkers, alert trend
- [ ] Write three custom detection rules mapped to specific MITRE ATT&CK techniques
- [ ] Understand false-positive tuning and alert fatigue
