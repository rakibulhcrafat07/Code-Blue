# Phase 5 — Detection & Hardening

Monitoring is half the job — closing off attack paths in the first place is the other half.

**Suggested pace:** Month 3
**Difficulty:** Intermediate

## Topics

- [ ] Read the MITRE ATT&CK Matrix; use ATT&CK Navigator
- [ ] Harden a Windows or Linux server against CIS Benchmarks
- [ ] Firewall rules hands-on (iptables / Windows Firewall)
- [ ] Install Suricata or Zeek and run it as an IDS
- [ ] Run a vulnerability scan with OpenVAS or Nessus Essentials
- [ ] Understand patch management and asset inventory basics
