**Phase:** [6 — Incident Response & Forensics](../)

## Objective

Reconstruct what happened on disk — file creation, execution, deletion — and put it on a timeline.

## Tasks

- [ ] Install Autopsy (and/or KAPE for targeted collection)
- [ ] Take a disk image of the lab VM, or use a public sample disk image
- [ ] Load it into Autopsy and explore the file system
- [ ] Recover deleted files if any are present
- [ ] Build a timeline of file system activity around the time of the (simulated) incident
- [ ] Identify persistence artifacts (startup items, scheduled tasks, prefetch, etc.)

## Tools

Autopsy, KAPE, a disk image (self-captured or a public DFIR sample)

## Deliverable

A timeline (even a simple table) of key filesystem events, plus a short note on what artifacts pointed to compromise.
