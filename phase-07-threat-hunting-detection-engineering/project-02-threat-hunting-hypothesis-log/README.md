# Project 2 — Threat Hunting Hypothesis Log

**Phase:** [7 — Threat Hunting & Detection Engineering](../)
**Status:** ⬜ To Do

## Objective

Practice hunting as a repeatable discipline: form a hypothesis, go look for evidence, record the result — whether or not you find anything.

## Tasks

- [ ] Form 3 hunting hypotheses based on ATT&CK techniques not yet covered by your existing detections (e.g., "an attacker might be using LOLBins to download files")
- [ ] For each, define what evidence would confirm or rule it out
- [ ] Search your SIEM/logs for that evidence
- [ ] Record the outcome for each — confirmed, ruled out, or inconclusive — and what you'd do next

## Tools

Your SIEM from Phase 4, MITRE ATT&CK for hypothesis ideas

## Deliverable

A hunting log: hypothesis → evidence sought → search performed → outcome, for all 3 hunts.
