# Project 4 — MISP Threat Intel Integration

**Phase:** [7 — Threat Hunting & Detection Engineering](../)
**Status:** ⬜ To Do

## Objective

Learn how threat intelligence feeds actually plug into detection, instead of treating IOCs as just a list to read.

## Tasks

- [ ] Stand up MISP (or use a hosted community instance) in the lab
- [ ] Import a public IOC feed (e.g., from AlienVault OTX)
- [ ] Pick 5 IOCs and write a detection rule/search that would alert if any of them appeared in your lab's logs
- [ ] Simulate a hit against one IOC and confirm the alert fires
- [ ] Note how you'd keep the feed current in a real environment (update cadence, expiry of stale IOCs)

## Tools

MISP, AlienVault OTX (or another free feed), your SIEM

## Deliverable

A short write-up: which IOCs you used, the detection built from them, and the simulated hit.
