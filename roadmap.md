# Blue Team Operations — Learning Roadmap

A structured, hands-on path into defensive security / blue team operations — from networking and OS fundamentals through SIEM, detection engineering, incident response, and threat hunting. Every phase builds on the last, and every project ships with setup notes, screenshots, and write-ups documenting the process.

All hands-on work lives under phase folders (starting with [`phase-01-beginner-foundations/`](./phase-01-beginner-foundations)), organized by phase and project.
